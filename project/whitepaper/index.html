Scaled Cognition: Whitepaper

Scaled Cognition’s whitepaper explains APT-1 and Agent Builder to enterprise buyers. The website had moved on, but the whitepaper was still in the old style. I rebuilt it on the new website styles, in light, mixed and dark editions.

Editorial Design
B2B Whitepaper
Design System in Figma

The Challenge

The whitepaper still used the old cyan palette, large type and heavy icons. Next to the new website it looked dated, and more like a brochure than a technical document.

The goal was to bring it in line with the website and make it read as a serious B2B document, while keeping all of the content and the page structure that already worked.

I pulled colours, type, radii and shadows from the website design, set them up as variables and text styles, then rebuilt every page on top of them. Product screens come from the latest Agent Builder designs.

Whitepaper

Colour variables with light and dark themes, a type scale in Hanken Grotesk and DM Sans, and a set of 1 px line icons. Every page is built from these, so a colour or type change updates the whole document.

Founders and backers up front, then the team, the Microsoft story and the training data, each with its own visual.

Eleven core features set in two columns with thin icons. The blue band highlights the three guarantees that matter most to buyers.

The live chat is linked to the code that controls it, so readers can see how copy types and function conditions shape a real conversation.

Four Agent Builder components with their screens, followed by professional services and a closing quote on navy.

Light for print, dark for screens and events, and mixed for a bit of both. Dark pages use the dark product screens, light pages use the light ones.

The same layouts on navy. Icons and accents stay in the brand blue so the dark edition still feels like the website.

The Result

Nine pages in three editions, all built on one set of styles taken from the website. The whitepaper now looks like it comes from the same company as the product and the site.

The type is smaller and lighter, icons are thin line icons, and every product screen is current. New pages can be added from the same styles without starting over.
